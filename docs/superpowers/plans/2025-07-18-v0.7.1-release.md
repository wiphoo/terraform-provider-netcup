## Resources

The following resources are available in the netcup provider:

- `netcup_server` - Manages server instances
- `netcup_server_snapshot` - Creates snapshots of servers for backup and recovery
- `netcup_server_snapshot_restore` - Restores servers from snapshots

## Operational Risk

> **⚠️ Destructive Operations Warning:**
>
> The `netcup_server_snapshot` and `netcup_server_snapshot_restore` resources perform destructive operations:
> - **`netcup_server_snapshot`**: Creates a server snapshot which requires server to be running and may cause downtime during snapshot creation
> - **`netcup_server_snapshot_restore`**: Restores a server from a snapshot, which will **overwrite existing data** and require server reboot
>
> **Risk:** Data loss is possible when restoring from snapshots. Always verify you have a backup of your data before performing restore operations.
> **Mitigation:** Test snapshots thoroughly before using restore operations in production environments.

## Usage Examples

See the `examples/` directory for usage examples.
```

def test_cosign_in_github_actions():
    import yaml
    import glob
    cosign_found = False
    for workflow_file in glob.glob(".github/workflows/*.yml"):
        with open(workflow_file, "r") as f:
            workflow = yaml.safe_load(f)
        for job_name, job_config in workflow.get("jobs", {}).items():
            if "steps" in job_config:
                for step in job_config["steps"]:
                    if "uses" in step and "cosign" in step["uses"]:
                        cosign_found = True

# .github/workflows/release.yml
name: Release

on:
  push:
    tags:
      - 'v*'

permissions:
  contents: write
  id-token: write

jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: '1.21'
      - name: Install cosign
        uses: sigstore/cosign-installer@v3.5.0
      - uses: goreleaser/goreleaser-action@v6
        with:
          version: latest
          args: release --clean
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      - name: Verify with cosign
        run: |
          cosign verify-blob \
            --certificate-identity-regexp 'https://github.com/' \
            --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
            --signature ./dist/checksums.txt.sig \
            --certificate ./dist/checksums.txt.pem \
            ./dist/checksums.txt
```
